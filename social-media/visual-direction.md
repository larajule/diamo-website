# diamo Visual Direction: Jeder Post, jedes Gefühl

## Die Leitfrage

> **Wenn jemand diesen Post sieht ohne den Namen zu lesen — weiß sie, dass es diamo ist?**

Wenn nein → Post ist nicht fertig.

---

## 1. Signature Elements (Was nur diamo macht)

### Das "d."
- Klein, dezent, immer gleich
- Font: Serif, italic
- Farbe: Lavender `#8B7FC7` oder Warm White (je nach Hintergrund)
- Position: Unten rechts, 5% vom Rand
- Größe: Gerade lesbar, nie dominant
- **Nicht auf jedem Post.** Nur auf Statements und Carousels.

### Die Lavender-Linie
- Ein dünner horizontaler Strich in Lavender
- Trennt Headline von Subtext
- Breite: 40px, Höhe: 1.5px
- **Nur auf Text-Posts** (THE WORD, THE FACT)
- Das ist euer visueller Fingerabdruck. Kein anderer Account hat das.

### Body-Close Fotografie
- diamo zeigt Körper ANDERS als andere Fitness-Accounts
- Nie den ganzen Körper. Immer **Ausschnitte**: Schulter, Hände, Rücken, Füße auf Matte
- Wie ein Kunstfotograf, nicht wie ein Fitness-Magazin
- Das macht euch sofort unterscheidbar im Feed

---

## 2. Die Profil-Erfahrung

### Was passiert wenn jemand auf @diamo.app landet:

**Sekunde 1: Der erste Eindruck**
- Bio lesen: "Dein Körper ist nicht jeden Tag gleich."
- Profilbild: Das "d." auf Navy-Kreis. Minimalistisch. Kein Logo-Monster.
- Gefühl: *"Das sieht anders aus als jeder andere Fitness-Account."*

**Sekunde 2: Das Grid**
- Abwechselnd warme Fotos und cleane Navy/Ivory Textflächen
- Wie ein aufgeschlagenes Magazin
- Viel Luft, viel Ruhe zwischen den Posts
- Gefühl: *"Das ist schön. Das will ich durchscrollen."*

**Sekunde 3: Die Entscheidung**
- Ein Statement-Post fällt ins Auge: "Pause ist Stärke."
- Daneben ein Foto: Frau von hinten, Sonnenlicht auf Schultern
- Gefühl: *"Die verstehen mich. Follow."*

## 3. Die 6 Templates im Detail

---

### ① THE MOMENT

**Was es ist:** Ein einzelnes Foto. Kein Text. Kein Logo. Nichts.

**Die Erfahrung der Betrachterin:**
Sie scrollt durch den Feed. Alles ist laut, bunt, Text überall. Dann — Stille. Ein Foto, das atmet. Eine Schulter im warmen Licht. Oder zwei Hände, die sich nach dem Training berühren. Sie hält an. Nicht weil Text sie auffordert. Sondern weil das Bild etwas in ihr auslöst.

**Visuell:**
```
┌─────────────────────────┐
│                         │
│                         │
│     [Foto: Nahaufnahme  │
│      Rücken einer Frau  │
│      im Morgenlicht,    │
│      leichte Bewegungs- │
│      unschärfe]         │
│                         │
│                         │
│                         │
└─────────────────────────┘
Kein Text. Kein Overlay. Nichts.
```

**Foto-Regeln:**
- Immer Nahaufnahme oder Anschnitt (nie Ganzkörper)
- Warmes, natürliches Licht (Golden Hour oder Fenster)
- Leicht entsättigt, warmer Farbton
- Bewegung darf unscharf sein (zeigt Lebendigkeit)
- Hauttöne natürlich. Nie bearbeitet.

**Motive (konkret):**
| Motiv | Stimmung | Jahreszeit |
|-------|----------|------------|
| Schweißtropfen auf Schlüsselbein | Stolz, Ehrlichkeit | Sommer |
| Hand greift Yoga-Matte | Anfangen, Ritual | Immer |
| Zwei Frauen von hinten, Arm in Arm | Verbindung | Immer |
| Füße auf nassem Gras, morgens | Frische, Erdung | Frühling |
| Haare im Wind beim Laufen | Freiheit | Herbst |
| Hände um eine Tasse nach dem Training | Ankommen, Ruhe | Winter |

**Caption:**
Max 1 Zeile + 1 Emoji. Oder nur ein Emoji.
> "Genau so. 🌿"
> "💜"
> "Heute war genug."

### ② THE WORD

**Was es ist:** Ein einzelner Satz auf Farbfläche. Reduziert auf das Maximum.

**Die Erfahrung der Betrachterin:**
Zwischen all den Fotos im Feed — eine ruhige Fläche. Navy. Ein Satz in warmem Weiß. Groß, mit viel Luft drumherum. Sie liest. Hält inne. Screenshottet. Sendet es einer Freundin.

**Visuell:**
```
┌─────────────────────────┐
│                         │
│          NAVY           │
│                         │
│                         │
│    "Dein Körper führt.  │
│     Immer."             │
│                         │
│    ─── (Lavender-Linie) │
│                         │
│                  d.     │
│                         │
└─────────────────────────┘
```

**Design-Regeln:**
- Hintergrund: Navy `#002060` (70%) oder Ivory `#F8F7F3` (30%)
- Text: Serif-Font (Cormorant Garamond oder Playfair Display)
- Textgröße: So groß wie möglich, dass es noch atmet
- Textfarbe: Warm White auf Navy, Navy auf Ivory
- Lavender-Linie unter dem Text: 40px breit, zentriert
- "d." unten rechts in Lavender, italic
- **Kein anderer visueller Schnickschnack**

**Sprache:**
- Max 6 Wörter
- Kein Ausrufezeichen. Punkt oder gar nichts.
- Klingt wie etwas, das eine weise Freundin sagt

**Beispiele:**
| Deutsch | English |
|---------|---------|
| "Dein Körper führt. Immer." | "Your body leads. Always." |
| "Pause ist Stärke." | "Rest is strength." |
| "Nicht jeden Tag gleich." | "Not the same every day." |
| "Gemeinsam bewegen." | "Move together." |
| "Du weißt es schon." | "You already know." |
| "Heute reicht das." | "Today, this is enough." |

**Caption:**
Kein Caption nötig. Oder eine einzige Frage:
> "Was brauchst du heute? 💬"

### ③ THE FACT

**Was es ist:** Eine überraschende Zahl oder ein Fakt. Visuell wie eine Buchseite.

**Die Erfahrung der Betrachterin:**
Eine große Zahl springt ihr entgegen. "20%" — was? Sie liest weiter. "mehr Kraft in deiner Follikelphase." Sie wusste das nicht. Sie saved den Post.

**Visuell:**
```
┌─────────────────────────┐
│                         │
│         IVORY           │
│                         │
│                         │
│        20%              │  ← Lavender, Serif, riesig
│                         │
│   ─── (Lavender-Linie)  │
│                         │
│   mehr Kraft in deiner  │  ← Navy, Sans, klein
│   Follikelphase.        │
│                         │
│                  d.     │
└─────────────────────────┘
```

**Design-Regeln:**
- Hintergrund: Immer Ivory `#F8F7F3`
- Große Zahl/Keyword: Lavender `#8B7FC7`, Serif, 80-120pt
- Erklärung darunter: Navy `#002060`, Sans-Serif, 16-20pt
- Lavender-Linie zwischen Zahl und Erklärung
- Viel vertikaler Whitespace (Zahl sitzt im oberen Drittel)

**Beispiele:**
| Zahl | Zeile darunter |
|------|----------------|
| 20% | mehr Kraft in deiner Follikelphase. |
| 3 Monate | hält Training alleine. Zusammen: ein Leben. |
| 28 Tage | Dein Körper verändert sich. Jeden einzelnen. |
| 30 Sek | Check-in am Morgen. Das reicht. |
| 4 Phasen | 4 verschiedene Körper. Eine App. |
| 0 | Wearables nötig. Dein Smartphone reicht. |

**Caption:**
1-2 Zeilen, erweitert den Fakt minimal:
> "Dein Östrogen steigt. Nutze die nächsten Tage. 💜"

### ④ THE STORY (Carousel)

**Was es ist:** Eine visuelle Geschichte in 4-5 Slides. Mehr Bild als Text.

**Die Erfahrung der Betrachterin:**
Slide 1 macht neugierig. Sie wischt. Jeder Slide gibt ihr genau einen Gedanken. Kein Scrollen durch Textblöcke. Eher wie Seiten in einem Bildband umblättern.

**Slide-Aufbau:**

**Slide 1 — Der Hook:**
```
┌─────────────────────────┐
│                         │
│          NAVY           │
│                         │
│                         │
│   "Warum sich dein      │  ← Warm White, Serif, groß
│    Training manchmal    │
│    falsch anfühlt."     │
│                         │
│         →               │  ← kleiner Pfeil, Lavender
│                         │
└─────────────────────────┘
```

**Slide 2-4 — Der Content:**
```
┌─────────────────────────┐
│                         │
│    IVORY oder FOTO      │
│                         │
│    [Icon oder Bild]     │  ← 60% des Slides
│                         │
│    Ein Satz.            │  ← Navy, Sans, max 12 Wörter
│    Nicht mehr.          │
│                         │
│              2/5        │  ← Seitenzahl, dezent
└─────────────────────────┘
```

**Slide 5 — Der CTA:**
```
┌─────────────────────────┐
│                         │
│    NAVY oder LAVENDER   │
│                         │
│                         │
│    "Speicher dir das."  │  ← Warm White, Serif
│                         │
│    💜                   │
│                         │
│                  d.     │
└─────────────────────────┘
```

**Regeln:**
- Nie mehr als 5 Slides
- Pro Slide: Max 12 Wörter Text
- Mind. 2 Slides mit Foto oder Illustration statt Text
- Seitenzahlen: dezent, unten rechts, Lavender
- Visueller Rhythmus: Navy → Ivory → Foto → Ivory → Navy

**Caption:**
Kurz. Die Story ist in den Slides.
> "Wisch weiter. 💜"

### ⑤ THE MOVE (Reel)

**Was es ist:** Bewegung. 10-20 Sekunden. Mehr Gefühl als Information.

**Die Erfahrung der Betrachterin:**
Es startet sofort. Kein Intro, kein "Hey Leute". Bewegung. Licht. Musik. Eine Frau die sich dehnt, im Park, morgens. Der Text kommt subtil: "Dein Körper weiß es." Dann Schnitt. Schwarz. "d."

**Aufbau:**

```
Sek 0-2:    Sofort Bewegung. Kein Vorspann.
            Frau dehnt sich / läuft / atmet tief

Sek 2-5:    Text-Overlay blendet ein (Untertitel-Stil)
            "Heute Mobility. Dein Körper hat recht."
            Font: Sans, weiß, leichter Schatten

Sek 5-15:   Weitere Bewegung. B-Roll. Verschiedene Winkel.
            Musik trägt. Text nur wenn nötig.

Sek 15-18:  Fade to Navy oder Schwarz
            "d." blendet ein (Lavender, Serif)

Sek 18-20:  Schwarzer Frame mit CTA-Text (optional)
            "Speichern für Low-Energy-Tage"
```

**Visuelle Regeln:**
- Kein Intro, kein Logo-Intro, kein "Hi ich bin..."
- Farb-Grading: Warm, leicht entsättigt (wie die Fotos)
- Schnitte: Langsam. Keine TikTok-Schnellschnitte. Ruhig, fließend.
- Musik: Emotional, Indie, Instrumental. Keine aggressiven Beats.
- Untertitel: IMMER. Sans-Serif, weiß mit leichtem Schatten. Zentriert unten.
- Custom Cover für Feed: Still-Frame + Serif-Text

**Cover-Design (für Feed):**
```
┌─────────────────────────┐
│                         │
│   [Still-Frame: Frau    │
│    von hinten, warmes   │
│    Licht]               │
│                         │
│                         │
│   "Heute reicht das."   │  ← Serif, weiß, unten
│                         │
└─────────────────────────┘
```

**Reel-Ideen:**
| Konzept | Länge | Musik-Vibe |
|---------|-------|------------|
| Morgens: Frau rollt Matte aus, stretcht, Sonne kommt rein | 15 Sek | Piano, ruhig |
| Zeitraffer: 4 Frauen kommen an, trainieren, High-Five am Ende | 20 Sek | Indie, aufbauend |
| Close-up Hände: greifen Matte, Wasser, dehnen, ruhen | 12 Sek | Ambient |
| Kontrastschnitte: HIIT vs. Mobility (gleiche Frau, verschiedene Tage) | 18 Sek | Beat-Wechsel |
| Eine Frau. Ein Park. Sonnenaufgang. Nur Atmen und Bewegen. | 15 Sek | Nur Naturgeräusche |

### ⑥ THE US

**Was es ist:** Echte Menschen. Lara, Marie, Community. Ungestellt.

**Die Erfahrung der Betrachterin:**
Ein Foto das aussieht wie aus dem Alltag. Nicht perfekt, aber echt. Zwei Frauen nach dem Training, verschwitzt, lachend. Oder Lara am Laptop mit einer Tasse. Sie denkt: *"Die sind echt. Denen vertrau ich."*

**Visuell:**
```
┌─────────────────────────┐
│                         │
│   [Foto: Authentisch,   │
│    leicht überbelichtet,│
│    warme Farben,        │
│    Snapshot-Feeling]    │
│                         │
│                         │
│                         │
│                         │
│                         │
└─────────────────────────┘
Kein Overlay. Optional: "d." unten rechts.
```

**Foto-Regeln:**
- Sieht aus wie ein guter Schnappschuss, nicht wie ein Shooting
- Leicht überbelichtet ist okay (gibt "Film-Gefühl")
- Lachen, Bewegung, echte Interaktion
- Nie gestellt. Nie "schau mal in die Kamera"
- Hintergründe: Café, Park, Büro, Gym. Echt.

**Motive:**
| Moment | Caption-Idee |
|--------|-------------|
| Lara + Marie am Whiteboard | "Montag, 9 Uhr." |
| Gruppe nach Workout, verschwitzt | "5 Fremde. 1 Stunde. Freundinnen." |
| Hand hält Kaffee, Laptop im Hintergrund | "Bauen. ☕" |
| Frauen stretchen im Park, von oben | "Samstag, 7 Uhr." |

**Caption:**
Ultra-kurz. Fast wie eine Bildunterschrift in einem Fotoband.
> "Montag, 9 Uhr."
> "5 Fremde. 1 Stunde. Freundinnen."

## 4. Der Gesamtcheck

Vor jedem Post, frag dich:

1. **Erkenne ich diamo ohne den Namen?** (Lavender-Linie, Farbpalette, Fotostil)
2. **Würde ich das einer Freundin schicken?** (Wenn nein → überarbeiten)
3. **Ist weniger möglich?** (Wenn ja → kürzen)
4. **Fühlt es sich an wie ein Magazin?** (Wenn nein → mehr Whitespace)
5. **Löst es etwas aus?** (Wenn nein → anderes Motiv/Satz)
