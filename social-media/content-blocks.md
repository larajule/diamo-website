# diamo Content Blocks: 6 Welten, 1 Brand

## Das System

Jeder Block ist wie eine eigene Kolumne in einem Magazin. Du schlägst die Seite auf und weißt sofort: *"Ah, das ist die Wissens-Rubrik"* oder *"Das ist die Community-Seite."*

Alle Blöcke teilen die diamo DNA (Serif-Headlines, warme Fotos, Lavender-Akzente). Aber jeder Block hat **eine eigene visuelle Sprache**, die ihn sofort erkennbar macht.

```
                    diamo Brand
         ┌──────────────┴──────────────┐
    Gemeinsam:                    Unterschiedlich:
    · Serif Headlines              · Akzentfarbe pro Block
    · Warme Fotografie             · Layout-Signatur
    · Lavender "d."                · Foto-Stil
    · Clean Whitespace             · Stimmung
```

## Block 1: 🧬 KÖRPERWISSEN

### Was es ist
Zykluswissen, Hormone, Körper verstehen. Die "Ah, das wusste ich nicht"-Momente.

### Warum es heraussticht
Andere Accounts machen Wissen = Textwände. diamo macht Wissen = **eine schöne Zahl und ein Satz.** Wie eine Infografik aus einem Architektur-Magazin.

### Akzentfarbe
**Sage** `#8FA98F` — Natur, Wachstum, Vertrauen

### Visuelles Erkennungszeichen
Eine **Sage-farbene Akzentlinie** links vertikal am Textblock. Wie ein Lesezeichen.

### Layout

**Single Fact:**
```
┌─────────────────────────┐
│                         │
│  │  IVORY               │
│  │                      │
│  │  "Dein Östrogen      │  ← Navy, Serif
│  │   steigt."           │
│  │                      │
│  │  Follikelphase:      │  ← Sage, Sans, kleiner
│  │  mehr Kraft,         │
│  │  mehr Ausdauer.      │
│  │                      │
│  │               d.     │
│  ↑ Sage Linie           │
└─────────────────────────┘
```

**Carousel (Wissens-Serie):**
- Slide 1: Sage Hintergrund, weiße Serif-Headline
- Slides 2-4: Ivory mit Sage-Linie links, je 1 Fakt
- Slide 5: Navy mit "Speicher dir das."

### Fotografie
- Makro-Details: Haut, Textur, Natur
- Botanisch: Blätter, Pflanzen, organische Formen
- Hände die den Bauch berühren, Körperbewusstsein

### Caption-Stil
Beginnt immer mit einem Fakt. Kurz. Kein Belehren.
> "Dein Progesteron steigt ab Tag 15. Dein Körper will jetzt Ruhe, nicht HIIT."
> 
> "Speichern. 🧬"

## Block 2: 💪 BEWEGEN

### Was es ist
Workouts, Übungen, Mobility, Dehnungen. Körper in Aktion.

### Warum es heraussticht
Kein "5 ÜBUNGEN FÜR FLACHEN BAUCH". Stattdessen: **Eine Frau. Eine Bewegung. Schön eingefangen.** Wie ein Tanz, nicht wie ein Tutorial.

### Akzentfarbe
**Warm Coral** `#D4886A` — Energie, Wärme, Lebendigkeit

### Visuelles Erkennungszeichen
**Bewegungsunschärfe** in den Fotos. Leicht verwischte Bewegung = Energie. Kein anderer Fitness-Account macht das bewusst.

### Layout

**Reel (Hauptformat):**
```
Sek 0:     Sofort Bewegung. Warm Coral Textblende:
           "MOBILITY"  (kurz, 0.5 Sek)
Sek 1-12:  Fließende Bewegung, warmes Licht
Sek 12-15: Fade out. "d." in Coral.
```

**Foto-Post:**
```
┌─────────────────────────┐
│                         │
│   [Foto: Frau in        │
│    Bewegung, leichte    │
│    Unschärfe, warmes    │
│    Licht, Anschnitt]    │
│                         │
│                         │
│                         │
│                         │
└─────────────────────────┘
Kein Text auf dem Bild.
```

### Fotografie
- Immer Bewegung sichtbar (keine statischen Posen)
- Anschnitte: Beine beim Laufen, Arme beim Stretchen
- Golden Hour, warme Töne, leichte Überbelichtung
- Location: Draußen, Parks, Treppen, Straße

### Caption-Stil
Ultra-kurz. Die Bewegung spricht für sich.
> "Follikelphase. Heute darf es laut sein. 💪"
>
> "20 Sekunden. Jeden Morgen."

## Block 3: 👋 WIR (Founder & Behind the Scenes)

### Was es ist
Lara und Marie. Der Weg. Die echten Momente hinter diamo.

### Warum es heraussticht
Jede App zeigt polierte Screenshots. Niemand zeigt **den Moment, in dem die Gründerinnen um 23 Uhr Pizza essen und trotzdem weitermachen.** Das schafft Vertrauen wie nichts anderes.

### Akzentfarbe
**Soft Gold** `#C4A96A` — Authentizität, Wärme, Gründer-Spirit

### Visuelles Erkennungszeichen
**Filmkorn-Look.** Alle WIR-Fotos haben einen leichten Analog-Film-Filter. Körnig, warm, etwas überbelichtet. Wie aus einer Einwegkamera. Sofort unterscheidbar.

### Layout

**Foto-Post:**
```
┌─────────────────────────┐
│                         │
│   [Foto: Filmkorn,     │
│    überbelichtet,       │
│    Lara am Laptop oder  │
│    Marie beim Training  │
│    oder beide zusammen] │
│                         │
│                         │
│                         │
│                         │
└─────────────────────────┘
Optional: "d." in Soft Gold, unten rechts
```

**Talking Head Reel:**
```
Sek 0:     Gesicht, direkt in Kamera. Kein Intro.
           "Ich hab 2 Jahre gegen meinen Zyklus trainiert."
Sek 1-15:  Ehrliche Story. Raw. Ungeschnitten.
Sek 15-18: "Deshalb gibt es diamo." Fade to Navy.
```

### Fotografie
- Filmkorn-Filter: Analog, körnig, warm
- Leicht überbelichtet, washed-out Farben
- Candid: nie gestellt, immer in Aktion
- Locations: Büro, Café, Küche, Gym. Echte Orte.

### Caption-Stil
Persönlich. Ich-Perspektive. Kurz aber verletzlich.
> "Mittwoch, 23 Uhr. Pizza und Pitch Deck."
>
> "Manchmal fragen wir uns, ob das verrückt ist. Dann erinnern wir uns, warum."

## Block 4: 👯‍♀️ ZUSAMMEN

### Was es ist
Community, Events, Gruppenworkouts, echte Verbindungen.

### Warum es heraussticht
**Immer mehrere Personen im Bild.** Das alleine macht es sofort anders als 90% des Fitness-Contents, der Einzelpersonen zeigt.

### Akzentfarbe
**Lavender** `#8B7FC7` — Verbindung, Sanftheit, diamo Core

### Visuelles Erkennungszeichen
**Immer 2+ Personen.** Wenn du diesen Block siehst, siehst du nie eine einzelne Frau. Immer Verbindung. Immer zusammen.

### Layout

**Foto-Post:**
```
┌─────────────────────────┐
│                         │
│   [Foto: 2-5 Frauen,   │
│    nach dem Training,   │
│    lachend, High-Five,  │
│    oder gemeinsam       │
│    dehnend. Warm.]      │
│                         │
│                         │
│                         │
│                         │
└─────────────────────────┘
```

**Event-Carousel:**
- Slide 1: Lavender Hintergrund, "Samstag. 7 Uhr. Ein Park."
- Slides 2-4: Fotos vom Event (echt, bewegt, lachend)
- Slide 5: "Nächstes Mal mit dir?" + CTA

### Fotografie
- Immer Gruppen (2, 3, 5 Frauen)
- Lachen, Berühren, High-Five, Arm in Arm
- Leicht chaotisch ist okay (zeigt Echtheit)
- Perspektive: Leicht von oben oder auf Augenhöhe

### Caption-Stil
Erzählerisch. Wie der Anfang einer Geschichte.
> "5 Fremde. 1 Park. 45 Minuten."
>
> "Jetzt planen sie schon nächsten Samstag. 👯‍♀️"

## Block 5: 🌙 FÜHLEN

### Was es ist
Mindset, Rest Days, Selbstfürsorge, emotionale Ehrlichkeit.

### Warum es heraussticht
**Dunklere, intimere Bildsprache.** Während alle anderen Blöcke hell und warm sind, ist FÜHLEN bewusst **ruhiger, dunkler, näher.** Wie ein Gespräch spät abends.

### Akzentfarbe
**Dusty Rose** `#B8919A` — Verletzlichkeit, Sanftheit, Tiefe

### Visuelles Erkennungszeichen
**Dunkle Farbpalette.** Weniger Licht, mehr Schatten. Moody. Die einzigen Posts im Feed, die bewusst dunkel sind.

### Layout

## Block 6: 📱 DIE APP

### Was es ist
App-Previews, Features, Beta, Produkt-Updates.

### Warum es heraussticht
**Kein platter Screenshot.** Jeder App-Post zeigt das Device in einem **Lifestyle-Kontext.** Handy liegt auf Yoga-Matte. Screen leuchtet neben einem Kaffee. Immer das Gefühl, nie die Funktion.

### Akzentfarbe
**Navy** `#002060` — Tech, Vertrauen, Produkt

### Visuelles Erkennungszeichen
**Device Mockup in Kontext.** Nie ein Screenshot alleine. Immer eingebettet in eine Szene.

### Layout

**Feature-Post:**
```
┌─────────────────────────┐
│                         │
│   [Foto: Handy auf      │
│    Yoga-Matte, Screen   │
│    zeigt diamo App,     │
│    daneben Wasserflasche,│
│    morgens, Sonnenlicht] │
│                         │
│                         │
│                         │
│                         │
└─────────────────────────┘
```

**Feature-Carousel:**
- Slide 1: Navy, "Was diamo morgens für dich tut."
- Slide 2: Foto: Handy auf Nachttisch, Wecker-Stimmung
- Slide 3: Close-up Screen mit Workout-Vorschlag
- Slide 4: Frau trainiert (die Übung von Slide 3)
- Slide 5: "Teste es selbst. Link in Bio."

### Fotografie
- Device immer in Szene eingebettet (nie freigestellt)
- Warme Umgebung: Holz, Textilien, Pflanzen drumherum
- Screen-Helligkeit reduziert (nicht blendend)
- Zeigt das Gefühl der Nutzung, nicht Features

### Caption-Stil
Fragt, statt zu erklären.
> "Was wäre, wenn dein Workout morgen schon auf dich wartet?"
>
> "Link in Bio. Begrenzte Plätze. 💜"

## So fügt sich alles zusammen

### Grid-Rotation
Nie 2x denselben Block hintereinander. Rotation:

```
Post 1:  🧬 KÖRPERWISSEN  (Sage)
Post 2:  💪 BEWEGEN        (Coral)
Post 3:  🌙 FÜHLEN         (Dunkel)
Post 4:  👯‍♀️ ZUSAMMEN       (Lavender)
Post 5:  👋 WIR            (Filmkorn)
Post 6:  📱 DIE APP        (Navy)
Post 7:  🧬 KÖRPERWISSEN   ...
```

### Das Grid-Ergebnis
```
┌──────────┬──────────┬──────────┐
│ 🧬 Hell  │ 💪 Warm  │ 🌙 Dunkel│  ← Hell, Warm, Dunkel
│ Sage     │ Coral    │ Rose     │
├──────────┼──────────┼──────────┤
│👯‍♀️ Gruppe │ 👋 Film  │ 📱 Navy  │  ← Menschen, Film, Tech
│ Lavender │ Gold     │ Navy     │
├──────────┼──────────┼──────────┤
│ 🧬 Hell  │ 💪 Warm  │ 🌙 Dunkel│  ← Muster wiederholt
│ Sage     │ Coral    │ Rose     │
└──────────┴──────────┴──────────┘
```

**Effekt:** Hell → Warm → Dunkel → Menschen → Film → Clean. Das Grid pulsiert visuell. Jede Reihe hat ihren eigenen Rhythmus, aber das Gesamtbild ist harmonisch.
